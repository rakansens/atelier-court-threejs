# PLAN A / Three.js 平面照合監査

参照元は、別repoのBlender版にある `scripts/layout_data.py` と、ユーザー提供の「PLAN A 再整合版｜東側スカイコートの家」です。Three.js側では、寸法を `app/housePlan.ts` に移し、すべての主要な床・壁・家具を同じ矩形座標から生成しています。

## 照合した項目

| 項目 | 正規寸法・位置 | Three.jsでの扱い |
| --- | --- | --- |
| 敷地 | 17.2m × 10.9m | `HOUSE_PLAN.site` |
| 建物 footprint | x=1.0–15.0 / y=1.8–8.2 | `HOUSE_PLAN.footprint` |
| 1F | ガレージ、SIC、玄関、仕事、畳、水回り、階段 | `rooms.one` の各矩形 |
| ガレージ | x=1.0–6.8 / y=1.8–8.0 | 西側道路に向くシャッターと車2台 |
| 2F LDK | x=2.45–11.35 / y=1.8–8.2 | LDK床、家具、キッチンを同じ座標で配置 |
| スカイコート | x=11.35–15.0 / y=4.0–8.2 | 2F床レベル3.3mに配置。地上水盤は作らない |
| 2F吹き抜け | x=4.8–11.35 / y=1.8–5.5 | 2Fの開口・低い手すりとして表現 |
| 2.5F | 寝室3、WIC、トイレ、ホール | `rooms.half`、ベッド、部分床 |
| 2.5F床なし部分 | 2F吹き抜け上部 | 2.5Fの `roofGroup` には床を置かない |
| 階高 | 1F 0.2 / 2F 3.3 / 2.5F 6.4m | `HOUSE_PLAN.levels` |

## 見つけて修正した違和感

1. 旧モデルの水盤が敷地地上にあり、2F東側スカイコートの意味が変わっていたため削除。2F床レベルへ移動。
2. 吹き抜けを高い壁で囲みすぎていたため、参照断面どおり低い手すり・開口に変更。
3. ガレージシャッターが南側の短辺に出ていたため、西側道路に沿う長辺へ移動。
4. 2.5F床とベッドを全体表示から欠落させていたため、全体ビューでも上部床・寝室が見えるよう修正。
5. 参照平面との照合用に、敷地・各室・中庭・吹き抜けの輪郭を重ねる `PLAN` 表示を追加。

## ブラウザ確認

- 全体、1F、LDK、2.5FをPlaywrightで切り替え確認。
- PLAN表示をON/OFFして、2F中庭がLDKの東側に接続することを確認。
- 夜景を確認し、上階寝室床の欠落がないことを確認。
- `npm run build`、`npm run lint`、`npm test`、`git diff --check` が通過。

これは設計検討用の3Dスタディであり、実施設計・建築確認・構造計算・法規・設備検証を代替するものではありません。
